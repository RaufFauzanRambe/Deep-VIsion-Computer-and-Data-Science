# ============================================================
# ULTRALYTICS YOLO - Object Detection (100% FREE)
# ============================================================
# Ultralytics YOLO (You Only Look Once) is a state-of-the-art object detection
# library that runs ENTIRELY LOCALLY on your machine.
# 
# HOW IT WORKS (No API Required):
# 1. The library downloads pre-trained models (yolov8n.pt, yolov8s.pt, etc.)
#    to your local cache on first use (~6MB for nano model)
# 2. All inference runs on YOUR CPU/GPU - no cloud API calls
# 3. The model is stored locally at ~/.config/ultralytics/ or ./weights/
# 4. No internet connection needed after initial model download
# 5. Zero API costs - unlimited detections forever
#
# Available Pre-trained Models (all free):
# - yolov8n.pt (nano - fastest, smallest)
# - yolov8s.pt (small)
# - yolov8m.pt (medium)
# - yolov8l.pt (large)
# - yolov8x.pt (extra large - most accurate)
